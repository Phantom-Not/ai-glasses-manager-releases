相机滤镜 · 2.6.3 新增

给拍摄画面换一种风格。

用自己的方式记录熟悉的风景。在管理器相机中试试 Matrix、Cyber Glitch 或 Prism，并看看下面的拍摄示例。

如何使用滤镜

  1. 打开管理器的相机。
  2. 打开滤镜选择面板，选择喜欢的风格。
  3. 关闭滤镜选择面板，回到相机取景画面。
  4. 点击管理器的快门按钮拍照。

Matrix

在眼前的风景中叠加绿色代码，拍出 Matrix 风格。

Cyber Glitch

让熟悉的画面出现彩色方块与数字故障效果。

Prism

让风景弯曲、旋转，呈现更超现实的视角。

点击任意照片，即可查看完整图片。

01

三种滤镜，都在同一个相机里

2.6.3 新增 Matrix、Cyber Glitch 和 Prism。可以直接在相机里选择风格，不必另开图片编辑应用。

滤镜的显示结果会随场景和光线变化。可以试试不同的拍摄对象，找到适合自己画面的风格。

02

拍照和录像控制

切换拍摄模式、使用取景画面、调整变焦和取景比例，并选择是否显示网格。相机设置中还可以控制快门和录像音效。

拍摄成功或失败时，会显示相应的视觉反馈。

03

拍完，直接查看

在图库中浏览照片和视频、查看图片、播放录像，也可以删除不再需要的媒体。界面按眼镜显示方式设计。

还可以通过管理器快捷方式，直接从 Rokid 启动器打开相机或图库。

图片为管理器的真实英文界面。显示效果可能随眼镜和应用版本而有所不同。
