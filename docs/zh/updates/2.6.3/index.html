AI Glasses Manager 2.6.3

三种相机滤镜与更方便的 APK 传输

相机新增 Matrix、Cyber Glitch 和 Prism。Wi-Fi Drop 支持上传 APK，再通过眼镜端文件管理器安装。

01

相机滤镜

  • 提供 Matrix、Cyber Glitch 和 Prism 三种选择。
  • 在管理器相机中为拍摄画面选择新风格。
02

APK 上传与安装

  • 在 Wi-Fi Drop 浏览器界面中上传 APK。
  • 在眼镜的文件管理器中打开 APK 进行安装，也可以通过商店安装受支持应用。
03

Wi-Fi Drop 与相机改进

  • 重新设计 Wi-Fi Drop 浏览器界面，并修复传输可靠性问题。
  • 改善相机界面的可读性。
