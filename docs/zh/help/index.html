安装与帮助

先装到眼镜上。

管理器是 Rokid 眼镜端应用。手机可以协助安装或付款，但应用应安装在你真正准备使用的眼镜上。

01

通过电脑安装

从官方发布页面下载 APK，把眼镜连接到已配置 Android 安装工具的电脑。如果使用 ADB，可以采用下面的命令。

也可以使用正常的 Android 安装器。之后可在应用内检查管理器更新。

adb install -r AI-Glasses-Manager-2.6.3.apk
AI Glasses Manager 是什么？

这是 Bruce 为 Rokid 眼镜独立开发的应用，原名 Rokid Manager，把应用商店、相机、图库、文件和设备控制整合在眼镜上。

它是 Rokid 官方手机应用吗？

不是。AI Glasses Manager 由 Bruce 独立开发，在眼镜上运行。Rokid 官方手机配套应用是另一款软件。

管理器开源吗？它是 awesome-rokid 的分支吗？

管理器是专有软件。公开 GitHub 仓库用于提供 APK、更新记录、截图和使用文档。awesome-rokid 等社区列表会链接到管理器，这并不表示管理器是它们的分支，也不表示应用源码已经公开。

应该装在哪里？

把 APK 安装到 Rokid 眼镜上。首次安装可使用 Android 安装器，或通过连接电脑进行安装，之后从 Rokid 启动器打开管理器。

从哪里下载？

请使用官方 GitHub 发布页面，或仓库 manager-update.json 列出的官方镜像。本站的下载按钮指向官方发布页面。

需要付费吗？

提供三天免费试用。之后每台设备一次性支付 1.99 美元进行激活，没有周期性订阅费用。国际付款通过 Stripe 完成。请使用应用内的激活页面，本站不提供付款或收款表单。

能用手机打开付款页面吗？

可以。手机可以打开与眼镜激活页面对应的付款页面。激活属于正在激活的那台设备。如果你在手机上单独安装并激活了管理器，不会同时激活眼镜。

重新安装或恢复眼镜出厂设置后怎么办？

同一台设备重新安装后通常会自动恢复激活。恢复出厂设置后可能需要私下联系支持进行核对。请向 Bruce 提供购买记录，不要把收据或激活信息发到公开问题区。

怎样更新管理器？

首次安装后，可以在管理器设置的应用更新中检查新版。本站的版本更新页面会逐个介绍已经发布的版本。

所有 Android 应用都能在眼镜上运行吗？

商店提供广泛的 Android 应用选择，但兼容性取决于具体应用和眼镜。有些应用需要触屏、手机服务或眼镜没有的硬件，部分条目也需要通过外部商店安装。

支持哪些眼镜和语言？

管理器为 Rokid 眼镜设计并测试，需要 Android 8.0 或更高版本。系统控制取决于固件。当前公开界面支持十种语言，完整列表见全部功能页面。

怎样反馈问题？

在官方仓库提交问题，说明管理器版本、眼镜型号和固件、当时的操作，以及复现步骤。截图中请移除个人文件、网络信息和设备标识。激活和购买问题请私下联系 Bruce。
