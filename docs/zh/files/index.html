文件管理与 Wi-Fi Drop

把文件传过来，在眼镜上打开。

本地文件交给文件管理器，手机或电脑里的文件可以用 Wi-Fi Drop 传输。

浏览本地文件通过 Wi-Fi 传文件上传 APK，并在眼镜上安装传输界面也更新了
01

浏览本地文件

在眼镜上打开文件夹、浏览存储空间和常见文件，也能进入相关的存储信息及 Android 系统工具。

它可以与相机和图库配合使用，让日常操作尽量在眼镜端完成。

02

通过 Wi-Fi 传文件

Wi-Fi Drop 提供浏览器传输界面，可供受支持的手机或电脑使用。按管理器显示的连接信息打开网页，再通过网页传输文件。

设置好后，不必每次传文件都重新连接 ADB。

03

上传 APK，并在眼镜上安装

2.6.3 新增通过 Wi-Fi Drop 上传 APK 的功能。先在浏览器中上传，再到眼镜的文件管理器中打开 APK 进行安装。

也可以通过内置商店寻找和安装受支持的应用。

  • 在管理器中打开 Wi-Fi Drop，按提示连接。
  • 在浏览器传输界面中上传 APK。
  • 在眼镜的文件管理器中找到上传的 APK。
  • 打开 APK，按 Android 安装提示完成操作。
04

传输界面也更新了

2.6.3 重新设计了 Wi-Fi Drop 浏览器界面，并改进了传输可靠性。版本记录会区分这些更新与之前已经加入的功能。
