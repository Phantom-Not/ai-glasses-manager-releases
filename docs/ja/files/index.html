ファイルと Wi-Fi Drop

ファイルを送って、眼鏡で開く。

眼鏡にあるファイルはファイルエクスプローラーで。スマートフォンやパソコンにあるファイルは Wi-Fi Drop で転送できます。

眼鏡の中のファイルを探すWi-Fi でファイルを送るAPK を送って、眼鏡上でインストール転送画面も使いやすく
01

眼鏡の中のファイルを探す

眼鏡上でフォルダーを開き、ストレージ内のファイルを閲覧できます。一般的な形式のファイルを開いたり、関連するストレージ設定や Android のシステム機能にアクセスしたりできます。

カメラやアルバムと合わせて、できるだけ眼鏡だけで作業を進められます。

02

Wi-Fi でファイルを送る

Wi-Fi Drop では、対応するスマートフォンやパソコンのブラウザーからファイルを転送できます。Manager に表示される接続方法に従い、ブラウザーの転送画面を開いてください。

接続を設定すれば、ファイルを送るたびに ADB でつなぐ必要はありません。

03

APK を送って、眼鏡上でインストール

2.6.3 では Wi-Fi Drop からの APK アップロードに対応しました。ブラウザーで APK を送り、眼鏡のファイルエクスプローラーから開くとインストールに進めます。

内蔵アプリストアからも、対応するアプリを探してインストールできます。

  • Manager で Wi-Fi Drop を開き、接続の案内に従います。
  • ブラウザーの転送画面から APK をアップロードします。
  • 眼鏡のファイルエクスプローラーで、転送した APK を探します。
  • APK を開き、Android の画面に従ってインストールします。
04

転送画面も使いやすく

2.6.3 では Wi-Fi Drop のブラウザー画面を刷新し、転送の安定性も改善しました。各バージョンで加わった機能は、更新情報のページで確認できます。
