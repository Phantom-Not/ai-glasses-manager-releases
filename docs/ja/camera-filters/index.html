カメラフィルター

いつもの景色に、自分らしい表情を。

Manager のカメラで6種類のフィルターを使えます。作例を選ぶと拡大表示できます。

フィルターの使い方

  1. Manager からカメラを開くか、Manager Camera のショートカットを使います。
  2. フィルター選択画面を開き、好きなフィルターを選びます。
  3. フィルター選択画面を閉じて、カメラのプレビューに戻ります。
  4. 画面の撮影ボタンまたは眼鏡の専用カメラボタンで、撮影や録画の開始・停止ができます。

Matrix

景色に緑のコードを重ねて、Matrix の世界観を楽しめます。

Cyber Glitch

見慣れた風景に、カラフルなブロックやデジタルな歪みを加えます。

Prism

景色を曲げたり渦巻かせたりして、少し不思議な眺めに。

VHS カムコーダー

トラッキングノイズ、色にじみ、日時表示で、アナログビデオの質感を再現します。

光の軌跡

明るい光を発光する軌跡に変え、背景の風景も見分けられるように残します。

プレデタービジョン

カメラ映像を、熱画像を思わせるコントラストの強い SF 風の色合いに変えます。

写真を選ぶと、全体を大きく表示できます。

01

カメラでスタイルを選ぶ

Matrix、Cyber Glitch、Prism、VHS カムコーダー、光の軌跡、プレデタービジョンの6種類です。

フィルターの見え方は、撮影するものや光の状態によって変わります。いろいろな被写体で試して、お気に入りの組み合わせを見つけてください。

02

写真も動画も、眼鏡で撮影

写真処理と撮影の安定性を改善し、バッテリー残量が少ないときの保護機能を追加しました。ズームも滑らかになりました。

眼鏡の専用カメラボタンで写真を撮影したり、録画を開始・停止したりできます。

カメラ設定で、タップしてからスワイプするズーム操作、グリッド線、アスペクト比を設定できます。

カメラ設定ではシャッター音や録画音も設定できます。撮影の成否は画面に表示されます。

03

撮ったあとも、そのまま眼鏡で

アルバムでは写真や動画を種類ごとに閲覧し、写真の表示、動画の再生、不要なファイルの削除ができます。眼鏡の画面に合わせた表示と操作で、撮影後もそのまま使えます。

Manager ショートカットを有効にすると、Rokid のランチャーからカメラやアルバムを直接開けます。

掲載画像は実際のアプリ画面です。スクリーンショットは英語表示のため、お使いの言語やバージョンによって見た目が異なる場合があります。
