内蔵アプリストア

眼鏡で使えるアプリを、もっと探そう。

普段使いの Android アプリから、Rokid 向けの個性的なプロジェクトまで。

幅広い Android アプリをひとつのストアでRokid 向け開発者アプリのコレクションダウンロードを自分のペースで読み込み済みの情報は、オフラインでも
01

幅広い Android アプリをひとつのストアで

Manager のストアには、厳選アプリや開発者アプリに加え、グローバル向け、中国で利用しやすいアプリなどのコレクションがあります。一般的な Android アプリも、眼鏡ならではのツールも探せます。

名前で検索したり、カテゴリーから探したり、詳細を確認してからインストールできます。掲載数は数千件規模ですが、提供元の状況によって内容は変わります。

  • アプリ、ユーティリティ、メディア関連ツールを探せます。
  • グローバル向けや中国で利用しやすいアプリのコレクションを閲覧できます。
  • アプリの詳細と利用できるダウンロード方法を確認できます。
02

Rokid 向け開発者アプリのコレクション

開発者アプリのコレクションでは、Rokid Glasses 向けに作られたコミュニティのアプリを紹介しています。幅広い Android アプリを扱うストアの、一部を構成するコレクションです。

ストアに掲載されているアプリを、すべて Manager が開発しているわけではありません。各アプリの権利や開発は、それぞれの提供者に帰属します。

03

ダウンロードを自分のペースで

ダウンロードは一時停止、再開、キャンセルができます。ストアを閉じてもバックグラウンドで続けられ、対応する APK のダウンロードが終わったら、眼鏡上でインストールに進めます。

  • いったん止めて、あとで再開できます。
  • 不要になったダウンロードをキャンセルできます。
  • ダウンロード済みの対応 APK をインストールできます。
  • 対応するインストール済みアプリの更新を確認できます。
04

読み込み済みの情報は、オフラインでも

接続が切れても、読み込み済みのアプリ情報は引き続き閲覧できます。オフライン時や接続に問題があるときには、その状況を画面で案内します。

提供元やダウンロード方法は変わることがあります。一部のアプリは外部ストアからの導入が必要です。また、眼鏡にないハードウェアや操作方法を前提とした機能は利用できない場合があります。

掲載画像は実際のアプリ画面です。スクリーンショットは英語表示のため、お使いの言語やバージョンによって見た目が異なる場合があります。
