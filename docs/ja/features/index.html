機能ガイド

Manager でできること。

現在公開中の 2.6.3 をもとに、眼鏡で使える機能をまとめました。

アプリストアとアプリの管理カメラと 3 つのフィルターアルバムで写真や動画を見るファイルエクスプローラーと Wi-Fi Drop端末と入力の設定音量とスワイプ時のフィードバックCleaner と Live IMU必要に応じて使える AI・音声操作Manager ショートカット画面表示・言語・アップデート
01

アプリストアとアプリの管理

厳選アプリ、開発者アプリ、グローバル向け、中国で利用しやすいアプリなど、数千件の Android アプリを閲覧できます。検索や詳細の確認、ダウンロード管理、対応 APK のインストールができます。

  • ダウンロードの一時停止、再開、キャンセル。
  • ストアを離れてもバックグラウンドでダウンロード。
  • 対応するインストール済みアプリの更新確認。
  • オフライン時も読み込み済みの情報を閲覧。
02

カメラと 3 つのフィルター

Manager のカメラで写真や動画を撮影できます。2.6.3 で追加した Matrix、Cyber Glitch、Prism からスタイルを選べます。

  • 撮影モード、画角、ズームの調整。
  • グリッドの表示切り替え。
  • シャッター音や録画時の音の設定。
  • 撮影の成功・失敗を画面で確認。
03

アルバムで写真や動画を見る

写真や動画を種類ごとに閲覧し、写真の表示、保存した動画の再生、不要なファイルの削除ができます。

アルバムを開くとメディア一覧が更新されます。表示や操作は、眼鏡の画面に合わせて設計しています。

04

ファイルエクスプローラーと Wi-Fi Drop

眼鏡のフォルダーを閲覧し、一般的な形式のファイルを開けます。Wi-Fi Drop のブラウザー画面を使えば、対応するスマートフォンやパソコンとファイルをやり取りできます。

Wi-Fi Drop でアップロードした APK は、ファイルエクスプローラーから開いてインストールできます。

05

端末と入力の設定

統一されたメニューから、Rokid や Android の設定にアクセスできます。Wi-Fi、Bluetooth、キーボード、インストール済みアプリ、ストレージ、バッテリー関連の機能を開けます。

利用できるシステム操作は、眼鏡のファームウェアや Android のバージョンによって異なります。

06

音量とスワイプ時のフィードバック

システム音量と眼鏡の音量を個別に調整できます。音量ロックで眼鏡の音量を一定に保ったり、スワイプ時のフィードバックを設定したりできます。

07

Cleaner と Live IMU

Cleaner ではワンタップのメンテナンスや、実行中アプリの確認ができます。

Live IMU ではコンパス、加速度、ジャイロ、ピッチ、ロールの情報を表示します。動きや向きを確認するときに、キャリブレーションやゼロ点調整も行えます。

08

必要に応じて使える AI・音声操作

ハンズフリーで使いたいときは、Manager 設定から AI マイクの表示を有効にできます。内蔵のコマンドガイドには、対応する英語と中国語の使用例を載せています。

AI を使わないときは、ホームからマイクの表示を隠せます。アプリの表示言語と、音声コマンドの対応言語は異なります。

09

Manager ショートカット

Rokid のランチャーに、カメラ、アルバム、アプリストア、ファイルエクスプローラーのショートカットを追加できます。それぞれの機能を直接開けます。

追加や削除は Manager 設定から行えます。

10

画面表示・言語・アップデート

AR モードや見やすいフォーカス表示など、眼鏡で使いやすい画面を目指しています。Manager 自体の更新は、Manager 設定の「アプリの更新」から確認できます。

公開中の 2.6.3 は、英語、簡体字中国語、繁体字中国語、広東語（香港）、日本語、韓国語、ロシア語、フランス語、ドイツ語、スペイン語の表示に対応しています。

掲載画像は実際のアプリ画面です。スクリーンショットは英語表示のため、お使いの言語やバージョンによって見た目が異なる場合があります。
