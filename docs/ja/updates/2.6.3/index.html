AI Glasses Manager 2.6.3

3 つのカメラフィルターと、より手軽な APK 転送

カメラに Matrix、Cyber Glitch、Prism を追加。Wi-Fi Drop で APK をアップロードし、眼鏡のファイルエクスプローラーからインストールできるようになりました。

01

カメラフィルター

  • Matrix、Cyber Glitch、Prism からスタイルを選べます。
  • Manager のカメラで、いつもの撮影に違う雰囲気を加えられます。
02

APK の転送とインストール

  • Wi-Fi Drop のブラウザー画面から APK をアップロードできます。
  • 転送した APK はファイルエクスプローラーから、対応アプリはアプリストアからインストールできます。
03

Wi-Fi Drop とカメラの改善

  • Wi-Fi Drop のブラウザー画面を刷新し、転送の安定性を改善しました。
  • カメラ画面の見やすさを改善しました。
