導入とサポート

まずは、眼鏡にインストール。

Manager は Rokid Glasses 上で使うアプリです。スマートフォンはインストールや支払いの補助に使えますが、アプリ本体は利用する眼鏡にインストールしてください。

01

パソコンからインストールする

公式リリースページから APK をダウンロードし、Android アプリをインストールできるよう設定したパソコンに眼鏡を接続します。ADB を使う場合は、次のコマンドでインストールできます。

通常の Android パッケージインストーラーを使う方法もあります。次回以降の Manager の更新は、アプリ内から確認できます。

adb install -r AI-Glasses-Manager-2.6.3.apk
AI Glasses Manager とは？

Bruce が Rokid Glasses 向けに個人で開発しているアプリです。旧名称は Rokid Manager です。アプリストア、カメラ、アルバム、ファイル管理、端末設定などを眼鏡上でまとめて使えます。

Rokid 公式のスマートフォン用アプリですか？

いいえ。Manager は個人開発のアプリで、眼鏡上で動作します。Rokid 公式のスマートフォン用コンパニオンアプリとは別の製品です。

オープンソースですか？ awesome-rokid の派生版ですか？

Manager はプロプライエタリソフトウェアで、アプリのソースコードは非公開です。公開 GitHub リポジトリでは APK、更新情報、スクリーンショット、使い方を配布しています。awesome-rokid などのコミュニティ一覧で紹介されていても、その派生版やオープンソースという意味ではありません。

どこにインストールすればよいですか？

APK は Rokid Glasses にインストールしてください。初回は Android のパッケージインストーラーや、接続したパソコンから導入できます。その後、Rokid のランチャーから Manager を開きます。

どこからダウンロードできますか？

公式 GitHub リリース、またはリポジトリの manager-update.json に記載された公式ミラーをご利用ください。このサイトのダウンロードリンクは、公式リリースページを開きます。

料金はいくらですか？

3 日間無料で試せます。その後は、端末 1 台につき 1.99 米ドルの買い切りです。定期課金はありません。国際決済には Stripe を利用します。有効化はアプリ内の有効化画面から行い、この案内サイトでは支払いを受け付けていません。

支払いページはスマートフォンで開けますか？

はい。眼鏡の有効化画面に対応する支払いページを、スマートフォンで開けます。ライセンスは有効化した端末に紐づきます。スマートフォンに別途インストールした Manager を有効化しても、眼鏡が同時に有効になるわけではありません。

再インストールや初期化をした場合は？

通常、同じ端末への再インストールでは有効化が復元されます。工場出荷時の状態に初期化した場合は、個別の確認が必要になることがあります。購入記録を用意して Bruce へ個別にご連絡ください。領収書や有効化に関する情報は、公開の Issue に投稿しないでください。

Manager はどうやって更新しますか？

初回インストール後は、Manager 設定の「アプリの更新」から新しいバージョンを確認できます。このサイトの更新情報では、公開済みの各バージョンの変更点を紹介しています。

すべての Android アプリが動きますか？

ストアには幅広いアプリがありますが、動作するかどうかはアプリと眼鏡によって異なります。タッチ操作、スマートフォン向けサービス、眼鏡にないハードウェアが必要なアプリもあります。一部の掲載アプリは外部ストアからの導入が必要です。

対応する眼鏡や言語を教えてください。

Manager は Rokid Glasses 向けに設計・検証しており、Android 8.0 以降が必要です。システム操作はファームウェアによって異なります。公開中のアプリは 10 言語の表示に対応しています。詳しくは機能ガイドをご覧ください。

不具合はどこに報告すればよいですか？

公式リポジトリの Issue に、Manager のバージョン、眼鏡の機種とファームウェア、発生時の操作、再現手順を添えてご報告ください。スクリーンショットから個人ファイル、ネットワーク情報、端末識別情報を除いてください。購入や有効化に関する内容は Bruce へ個別にご連絡ください。
