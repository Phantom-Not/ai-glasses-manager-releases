カメラフィルター

いつもの景色を、少し違う一枚に。

見慣れた街角も、静かな田園も、海辺の風景も。Manager のカメラで Matrix、Cyber Glitch、Prism を選んで、自分らしい一枚にしてみませんか。

フィルターと使い方を見る ↗

Matrix

景色に緑のコードを重ねて、Matrix の世界観を楽しめます。

Cyber Glitch

見慣れた風景に、カラフルなブロックやデジタルな歪みを加えます。

Prism

景色を曲げたり渦巻かせたりして、少し不思議な眺めに。

写真を選ぶと、全体を大きく表示できます。
