AI Glasses Manager 2.6.3

Three camera filters and easier APK transfers

Matrix, Cyber Glitch and Prism arrive in Camera. Wi-Fi Drop adds APK uploads, with installation through File Explorer on the glasses.

01

Camera filters

  • Choose from Matrix, Cyber Glitch and Prism.
  • Use Manager’s Camera tools to give your captures a new look.
02

APK uploads and installation

  • Upload APKs from the Wi-Fi Drop browser interface.
  • Open an uploaded APK in File Explorer to install it, or install supported apps from the App Store.
03

Wi-Fi Drop and Camera improvements

  • A redesigned Wi-Fi Drop browser interface and transfer reliability fixes.
  • Clearer Camera interface readability.
