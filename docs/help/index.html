Install & help

Start on the glasses.

Manager is an app for Rokid Glasses. Your phone can help with installation or payment, but the app belongs on the glasses you want to use.

01

Install from a computer

Download the APK from the official release page, connect your glasses to a computer set up for Android installation, then use the command below if you install through ADB.

You can also use the normal Android package installer. Future Manager updates can be checked from inside the app.

adb install -r AI-Glasses-Manager-2.6.3.apk
What is AI Glasses Manager?

An independent app by Bruce for Rokid Glasses. It was previously called Rokid Manager. It brings apps, camera tools, Gallery, files and device controls together on the glasses.

Is this Rokid’s official phone app?

No. AI Glasses Manager is independently developed and runs on the glasses. Rokid’s official phone companion is a separate app.

Is the Manager open source or an awesome-rokid fork?

Manager is proprietary software. The public GitHub repository distributes its APKs, release notes, screenshots and documentation. Community lists such as awesome-rokid link to it; they do not make it a fork or publish the application source.

Where do I install it?

Install the APK on your Rokid Glasses. Use the Android package installer or a connected computer for the initial installation. Open Manager from the Rokid launcher afterwards.

Where should I download it?

Use the official GitHub releases or an official mirror listed in the repository’s manager-update.json. The download buttons on this site point to the official release page.

How much does it cost?

There is a three-day free trial. Afterwards, activation costs $1.99 per device, paid once, with no recurring subscription. International payments use Stripe. Activation takes place through the app’s activation page, not on this documentation site.

Can my phone open the payment page?

Yes. Your phone can open the checkout associated with the glasses’ activation page. Activation belongs to the device being activated. Installing and activating a separate copy of Manager on a phone does not also activate your glasses.

What happens if I reinstall or reset my glasses?

Activation is normally restored after reinstalling on the same device. A factory reset may need a private support review. Contact Bruce with your purchase record; do not post receipts or activation details in a public issue.

How do I update Manager?

After the first installation, open Manager Settings > App Update to check for a newer Manager release. The Updates pages here describe what changed in each public version.

Will every Android app work on the glasses?

The catalogue contains a wide selection of Android apps, but compatibility depends on the app and glasses. Some apps expect touch input, phone services or hardware that the glasses do not provide. Some listings need an external store rather than direct APK installation.

Which glasses and languages are supported?

Manager is designed and tested for Rokid Glasses and requires Android 8.0 or later. System controls depend on firmware. The current public interface supports ten languages; see the full feature guide for the list.

How do I report a problem?

Open an issue in the official repository with your Manager version, glasses model and firmware, what you were doing, and the steps to reproduce it. Remove personal files, network details and device identifiers from screenshots. For activation and purchase details, contact Bruce privately.
