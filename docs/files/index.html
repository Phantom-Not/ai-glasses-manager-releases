Files & Wi-Fi Drop

Move a file. Open it on the glasses.

Use File Explorer for local storage and Wi-Fi Drop when the file is still on your phone or computer.

Browse local filesSend files over Wi-FiAPK uploads and on-glasses installationA refreshed transfer interface
01

Browse local files

Open folders, browse local storage and open common files from the glasses. File Explorer also gives you a route to related storage and Android system tools.

You can use it alongside Camera and Gallery without turning every task into a phone-side workflow.

02

Send files over Wi-Fi

Wi-Fi Drop lets supported phones and computers transfer files through a browser interface. Follow the connection details shown by Manager, then use that browser page to move your files.

Once it is set up, you do not need to connect through ADB for every transfer.

03

APK uploads and on-glasses installation

Version 2.6.3 added APK uploads through Wi-Fi Drop. Upload the APK from your browser, then open it in File Explorer on the glasses to install it.

You can also discover and install supported apps through the built-in App Store.

  • Open Wi-Fi Drop in Manager and follow its connection instructions.
  • Use the browser interface to upload your APK.
  • Find the uploaded APK in File Explorer on the glasses.
  • Open the APK and follow the Android installation prompts.
04

A refreshed transfer interface

The 2.6.3 update redesigned the Wi-Fi Drop browser interface and improved transfer reliability. The version history keeps these changes separate from features added in earlier releases.
